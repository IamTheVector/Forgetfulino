## Forgetfulino 2.0.0

Forgetfulino is an Arduino library and Arduino IDE 2.x extension that **embeds your sketch source code into firmware flash** and lets you **recover it later via Serial**.

This repository contains two main parts:

- **Forgetfulino-main/** – the Arduino library (this is what goes into your `Arduino/libraries` folder or is picked by the Arduino Library Manager).
- **extension build/** – the full development project for the Arduino IDE 2.x extension (TypeScript, `package.json`, build scripts, etc.). This folder is **not** shipped to end users through the Library Manager.

The `.vsix` file that users install in Arduino IDE lives inside `Forgetfulino-main/extensions/` and is very small.

------------------------------------------------------------

## Library overview

- Stores the **exact sketch sources** (all `.ino` and `.cpp` files) in **PROGMEM**.
- **Zero RAM** usage for storage: everything stays in flash.
- Uses **deflate compression + Base64**:
  - The extension compresses the merged sketch with deflate (zlib compatible).
  - The library dumps the compressed bytes as a **single Base64 line** over Serial.
  - The extension decodes Base64, inflates, and reconstructs the original UTF‑8 source.
- Supports both:
  - **plain text dump** (`Forgetfulino.dumpSource()`),
  - **compressed dump** (`Forgetfulino.dumpCompressed()`).
- Provides an **on-demand mode** that only dumps when you type `forgetfulino` on the Serial Monitor:
  - `Forgetfulino.dumpSource_OnDemand();`
  - `Forgetfulino.dumpCompressed_OnDemand();`
- The IDE extension:
  - auto‑generates the headers on save,
  - injects ready‑to‑use templates into new sketches,
  - decodes dumps and **adds version comments** to each `#include`,
  - cleans up the pasted Base64 line after decoding.

For detailed usage, examples and API reference, see `Forgetfulino-main/README.md`.

## Repository layout

- **Forgetfulino-main/**  
  Arduino library root used by the Arduino Library Manager (version **2.0.0**):
  - `library.properties` – Arduino metadata.
  - `src/` – library sources (`Forgetfulino.h`, `Forgetfulino.cpp`) and generated headers:
    - `forgetfulino_source_data.h` (plain source, generated by the extension),
    - `forgetfulino_compressed.h` (compressed source, generated by the extension).
  - `examples/` – example sketches.
  - `extensions/` – packaged Arduino IDE 2.x extension (`forgetfulino-arduino-ide-extension-*.vsix`) and `README-Extensions.txt`.
  - `README.md` – end‑user manual for the library + extension.

- **extension build/**  
  Full development project for the Arduino IDE 2.x extension:
  - `package.json`, `tsconfig.json`, `src/extension.ts`…
  - Built with `npm run compile` and packaged with `npm run package`.
  - Produces `forgetfulino-arduino-ide-extension-0.0.1.vsix`, which must be copied into `Forgetfulino-main/extensions/`.

## Building the IDE extension (for maintainers)

From the repository root:

```bash
cd "D:\LAVORO\FORGETFULINO\TEST BUILD\extension build"
npm install        # first time only
npm run compile    # build TypeScript
npm run package    # create the VSIX
```

The VSIX file will be created as:

```text
extension build/forgetfulino-arduino-ide-extension-0.0.1.vsix
```

Copy or move it to the Arduino library folder so that end users get it with the library:

```bash
copy "extension build\forgetfulino-arduino-ide-extension-0.0.1.vsix" "Forgetfulino-main\extensions\forgetfulino-arduino-ide-extension-0.0.1.vsix"
```
