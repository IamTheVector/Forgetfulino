## Forgetfulino 2.0.0 – Arduino library + IDE extension

Forgetfulino embeds your **Arduino sketch source code** into firmware flash (PROGMEM) and lets you **recover it later via Serial**, even if the original `.ino` files are gone.

Version **2.0.0** introduces:

- **True compression**: deflate (zlib) + Base64 instead of Base85 text.
- A robust **Arduino IDE 2.x extension** that generates headers, injects templates, and decodes dumps.
- **On-demand dump mode**: type `forgetfulino` on the Serial Monitor to trigger a dump only when you need it.
- Automatic **library version annotations** on `#include` lines in the recovered source.
- Cleaner UX: Base64 dump on a single logical line, timestamp stripping, and automatic removal of the pasted dump line after decoding.

------------------------------------------------------------

## 1. Folder layout (inside the library)

Installed under `Arduino/libraries/Forgetfulino` (or `Forgetfulino-main` depending on your setup):

- `library.properties` – Arduino metadata (version **2.0.0**, MIT license).
- `src/`
  - `Forgetfulino.h`, `Forgetfulino.cpp` – core library.
  - `forgetfulino_source_data.h` – **plain merged source**, generated by the IDE extension.
  - `forgetfulino_compressed.h` – **deflate-compressed source**, generated by the IDE extension.
- `examples/`
  - Example sketches showing basic and advanced usage.
- `extensions/`
  - `forgetfulino-arduino-ide-extension-0.0.1.vsix` – packaged Arduino IDE 2.x extension.
  - `README-Extensions.txt` – how to install the VSIX manually.
- `README.md` – this document.

> The heavy **extension development project** (TypeScript, `node_modules`, etc.) lives in the repository root under `extension build/` and is not shipped with the Arduino Library Manager.

## 2. Installing the library

### 2.1 Arduino Library Manager (recommended once published)

When Forgetfulino is available in the Library Manager:

1. Open **Arduino IDE**.
2. `Sketch → Include Library → Manage Libraries…`
3. Search for **Forgetfulino**.
4. Click **Install**.

The Library Manager will install the contents of `Forgetfulino-main/` as the library.

### 2.2 Manual installation from this repository

1. Download or clone the repository.
2. Copy the `Forgetfulino-main` folder into your Arduino `libraries` folder and (optionally) rename it to `Forgetfulino`.
3. Restart Arduino IDE.

Typical `libraries` locations:

- **Windows**: `Documents/Arduino/libraries/`
- **macOS**: `~/Documents/Arduino/libraries/`
- **Linux**: `~/Arduino/libraries/`

## 3. Installing the IDE extension (VSIX)

The Forgetfulino extension for **Arduino IDE 2.x** is shipped inside the library to keep everything together.

Files in `extensions/`:

- `forgetfulino-arduino-ide-extension-0.0.1.vsix`
- `README-Extensions.txt`

### 3.1 Quick install

1. Close **Arduino IDE 2.x**.
2. Locate your `.arduinoIDE` configuration folder:
   - Windows: `C:\Users\<you>\.arduinoIDE\`
   - macOS: `/Users/<you>/.arduinoIDE/`
   - Linux: `/home/<you>/.arduinoIDE/`
3. Create (if needed) the subfolder: `.arduinoIDE/extensions/`
4. Copy the Forgetfulino VSIX from the library:

   - From: `Arduino/libraries/Forgetfulino/extensions/forgetfulino-arduino-ide-extension-0.0.1.vsix`
   - To:   `.arduinoIDE/extensions/forgetfulino-arduino-ide-extension-0.0.1.vsix`

5. Start **Arduino IDE 2.x** again.
6. Check `.arduinoIDE/deployedPlugins/` to verify that a folder containing `forgetfulino-arduino-ide-extension` has been deployed.

Once deployed, the extension becomes available in all Arduino IDE 2.x windows.

## 4. Library API (C++ on the board)

The library exposes a single global instance:

```cpp
#include <Forgetfulino.h>

// Global instance
extern ForgetfulinoClass Forgetfulino;
```

### 4.1 Core methods

- **`void Forgetfulino.begin();`**
  - Call once in `setup()` after `Serial.begin(...)`.
  - Prints a small banner (`"Forgetfulino is here"`) on Serial so you can see that the library is active.

- **`void Forgetfulino.dumpSource();`**
  - Prints the embedded **plain-text source** to `Serial`, including all collected `.ino`/`.cpp` files.
  - Intended mainly for human-readable inspection; consumes more flash than the compressed form.

- **`void Forgetfulino.dumpCompressed();`**
  - Prints a **single Base64 line** representing the deflate-compressed source.
  - Also prints a short header:
    - original size (bytes),
    - compressed size (bytes),
    - expected Base64 length (characters).
  - This is what you usually decode with the IDE extension.

### 4.2 On-demand mode (trigger word `forgetfulino`)

These helpers are designed to be called from `loop()` without blocking your application:

- **`void Forgetfulino.dumpSource_OnDemand();`**
- **`void Forgetfulino.dumpCompressed_OnDemand();`**

Behavior:

- They non‑blocking‑poll `Serial` and look for the keyword **`forgetfulino`**:
  - Case-insensitive (`Forgetfulino`, `FORGETFULINO`, etc.).
  - Leading/trailing spaces and tabs are ignored.
  - Works both when the Serial Monitor sends a newline (`\r`, `\n`…) and when **no line ending** is sent (exact 11 characters).
- When a match is detected, they call the corresponding dump function once.

Typical usage in `loop()`:

```cpp
void loop() {
  // Only dump when the user types "forgetfulino" in the Serial Monitor.
  Forgetfulino.dumpCompressed_OnDemand();
  // Or, for plain text:
  // Forgetfulino.dumpSource_OnDemand();

  // ...your normal logic here...
}
```

> Tip: this avoids printing the dump at every reboot and keeps the Serial Monitor clean until you explicitly ask for it.

## 5. How the compression pipeline works

On the **PC side** (IDE extension):

1. The extension collects all sketch source files (`.ino` and `.cpp`) in the sketch folder.
2. It **sanitizes** the source (removes problematic Unicode, optional comment stripping).
3. It compresses the merged text with **deflate** (`zlib.deflateRawSync`).
4. It generates:
   - `forgetfulino_source_data.h` (plain source in PROGMEM).
   - `forgetfulino_compressed.h` (compressed bytes in a `const uint8_t[] PROGMEM`).

On the **board side**:

1. `Forgetfulino.dumpCompressed()` reads the compressed bytes from PROGMEM.
2. It converts them to **Base64** on the fly and prints them as a **single line** to `Serial`, with gentle throttling to avoid buffer overflows.

On the **PC side again** (IDE extension):

1. You copy/paste or select the Base64 line.
2. The extension removes timestamps (e.g. `HH:MM:SS.mmm ->` from the Serial Monitor).
3. It decodes Base64 → inflates via deflate → recovers the original UTF‑8 text.
4. It post-processes the text, adding `// version ...` comments to each `#include`.

## 6. Arduino IDE 2.x extension – commands and menus

Once installed, the extension adds several commands to the **command palette** and the **right‑click menu** on `.ino` files.

### 6.1 Context menu – injection

Right‑click inside a `.ino` file:

- **Inject → Inject in setup (show dump every reboot)**  
  - Inserts `#include <Forgetfulino.h>` (if missing).
  - Ensures `Serial.begin(115200);` and `Forgetfulino.begin();` are called in `setup()`.
  - Adds a one‑shot `Forgetfulino.dumpCompressed();` call in `setup()` so every reset prints the dump.

- **Inject → Inject in loop (show dump when you write forgetfulino in serial)**  
  - Inserts `#include <Forgetfulino.h>` (if missing).
  - Ensures `Serial.begin(115200);` and `Forgetfulino.begin();` are called in `setup()`.
  - Adds:
    ```cpp
    Forgetfulino.dumpCompressed_OnDemand();
    // Forgetfulino.dumpSource_OnDemand();
    ```
    at the start of `loop()`.
  - Nothing is printed at reboot; the dump appears only when you type `forgetfulino` on the Serial Monitor.

There is also the legacy command **“Forgetfulino: Inject template now”** which behaves like “Inject in setup”.

### 6.2 Context menu – auto‑inject

The **Auto Inject** submenu lets you configure how **new** sketches (empty or default Arduino skeleton) are populated on first save:

- **Auto Inject → Inject in setup (show dump every reboot)**  
  - Enables `forgetfulino.autoInjectTemplate = true`.
  - Sets `forgetfulino.autoInjectMode = "setup"`.
  - New `.ino` files receive a template with `dumpCompressed()` in `setup()`.

- **Auto Inject → Inject in loop (show dump when you write forgetfulino in serial)**  
  - Enables `forgetfulino.autoInjectTemplate = true`.
  - Sets `forgetfulino.autoInjectMode = "loop"`.
  - New `.ino` files receive a template with `dumpCompressed_OnDemand()` in `loop()`.

- **Auto Inject → Deactivate**  
  - Sets `forgetfulino.autoInjectTemplate = false`.

### 6.3 Other commands

- **Generate headers**  
  - `Forgetfulino: Generate headers`
  - Collects the current sketch sources and regenerates:
    - `src/forgetfulino_source_data.h`
    - `src/forgetfulino_compressed.h`

- **Auto‑generate on save**  
  - `Forgetfulino: Activate auto-generate on save`
  - `Forgetfulino: Deactivate auto-generate on save`
  - Controlled by `forgetfulino.autoGenerateOnSave` (boolean).

- **Comments in dump**  
  - `Forgetfulino: Click to activate comment in dump`
  - `Forgetfulino: Click to deactivate comment in dump`
  - Controlled by `forgetfulino.includeCommentsInDump` (boolean).
  - When disabled, comments are stripped before embedding, producing smaller dumps.

## 7. Decoding a compressed dump (in the IDE)

Workflow:

1. On the board, call **either**:
   - `Forgetfulino.dumpCompressed();` (e.g. in `setup()`), or
   - `Forgetfulino.dumpCompressed_OnDemand();` (in `loop()` and then type `forgetfulino`).
2. In the **Serial Monitor**:
   - Select the long Base64 line, or
   - Paste that line into an editor tab inside Arduino IDE.
3. Right‑click the line and choose **“Forgetfulino: Decode compressed dump”**.

The extension will:

- Strip Serial Monitor timestamps like `HH:MM:SS.mmm ->` from all lines.
- Remove whitespace and line breaks from the selected text.
- Base64‑decode and deflate the data back to UTF‑8 source.
- Add `// version X.Y.Z` (or `// version number` if unknown) after each `#include` line.
- Open the recovered source in a **new editor tab** (language set to C++).
- **Delete the original Base64 line/selection** from the source file where you pasted it, keeping your sketch tab clean.

If decoding fails, an error message is shown and the original text is left untouched.

## 8. Basic usage example (one‑shot dump)

```cpp
#include <Forgetfulino.h>

void setup() {
  Serial.begin(115200);
  delay(2000);

  Forgetfulino.begin();

  // One-shot compressed dump on boot.
  // Use the “Decode compressed dump” command in the IDE to recover the source.
  Forgetfulino.dumpCompressed();
}

void loop() {
  // Your normal application code here.
}
```

## 9. Basic usage example (on-demand)

```cpp
#include <Forgetfulino.h>

void setup() {
  Serial.begin(115200);
  Forgetfulino.begin();
}

void loop() {
  // Only dump when you type "forgetfulino" in the Serial Monitor.
  Forgetfulino.dumpCompressed_OnDemand();
  // Forgetfulino.dumpSource_OnDemand();

  // Your normal application code here.
}
```
